# 机械臂控制与六维力传感器采集界面 V3

本目录以 `sensor_2_control_v2` 为基础创建。机械臂控制、位置记忆、贯入
试验、剪切试验、图表和主题功能保持不变，传感器改为项目根目录中的
`sensor_6/` 六维力/力矩传感器模块。

## 启动

从项目根目录运行：

```powershell
C:\Users\www61\anaconda3\envs\common\python.exe apps\sensor_6_control_v3\main.py
```

也可以进入本目录后运行：

```powershell
C:\Users\www61\anaconda3\envs\common\python.exe main.py
```

## 目录内容

- `main.py`：主程序入口、六维采集线程、试验控制和 XLSX 保存；
- `main_window_3.py`、`main_window_3.ui`：完整的 V3 界面、图表和交互逻辑；
- `main_window.py`、`main_window.ui`：历史基础界面文件，V3 不再导入；
- `picture/`：窗口与界面使用的吉林大学图标。

## 六维数据约定

- 传感器原始通道顺序为 `Fx、Fy、Fz、Mx、My、Mz`；
- 界面和导出文件将力矩通道显示为 `Tx、Ty、Tz`；
- `Fx、Fy、Fz` 单位为 N，`Tx、Ty、Tz` 单位为 N·m；
- 贯入试验以 `Fz` 绘图并判断力上限；
- 剪切试验以 `Tz` 绘图并判断扭矩上限；
- 剪切角位移允许输入 `-360°～360°`，负值使 J6 反向运动，曲线和
  XLSX 中的角位移也保留负号；
- 两种试验的 XLSX 都保存起点置零后的全部六维数据，以及世界坐标和
  J1～J6 关节角。

界面提供 Fx、Fy、Fz、Tx、Ty、Tz 六个单通道清零按钮，以及一个全部
清零按钮。底层 Modbus 参数和清零功能由根目录 `sensor_6/` 统一维护。

## 堆叠页面

- 右侧试验区第一页为贯入试验和剪切试验，第二页为铲挖试验；
- 铲挖页包含位移速度，以及 B、C、D、E、F、G 六个路径点各自的 X/Y/Z 世界坐标
  增量，单位均为 mm；
- 启动时以当前末端位姿为起点，依次执行“当前点→B→C→D→E→F→G”。每个点的
  增量均相对上一个点，Rx/Ry/Rz 保持不变；实时位姿连续确认稳定到位后
  才发送下一段，不会一次性压入全部运动命令；
- 某一点的 X/Y/Z 增量全部为0时自动跳过该点；六个点全部为0时不发送
  任何机械臂运动指令；
- 铲挖启动会清空并切换到六维力页面，实时显示 Fx/Fy/Fz 压力曲线和
  Tx/Ty/Tz 扭矩曲线；执行完 G 点前的全部有效增量后自然结束，不发送停止或失能指令；
- 铲挖保存生成 `shovel_motor_时间_编号.xlsx`，保存时间、当前阶段、
  相对 XYZ 位移、累计空间位移、六维力、原始世界位姿和 J1～J6；重置
  会清空铲挖数据与六维力的两幅曲线；
- 右侧栏默认宽度调整为约 410 px，并限制在 390～450 px；B～G 六行的
  点名称、XYZ 输入框和单位采用统一宽度与对齐方式，三个操作按钮统一为
  110×34 px，在全屏和高 DPI 下均保留完整文字和输入区域；
- 中间显示区第一页为末端位移-力与角位移-扭矩，第二页为六维力实时曲线；
- 六维力页分别显示 Fx/Fy/Fz 和 Tx/Ty/Tz 随时间变化的两组曲线，支持
  显示、关闭和重置。

## 试验参数记忆

以下参数与 P1～P5 位置记忆一起保存在应用目录的
`sensor_6_control_v3.ini`：

- 贯入试验：位移速度、位移距离、力最大值；
- 剪切试验：角速度、角位移、扭矩最大值；
- 铲挖试验：位移速度，以及 B～G 点各自的 X/Y/Z 增量。

参数修改后立即保存，软件退出时再次统一保存；下次启动自动恢复上次输入。
试验参数位于 INI 的 `test_parameters` 分组，位置记忆位于
`position_memory` 分组，二者互不覆盖。

源码运行时 INI 位于本目录；EXE 运行时位于 EXE 同级目录。首次使用本
实现时，程序会从旧的 Windows 注册表设置导入已有记忆，之后只使用 INI。
