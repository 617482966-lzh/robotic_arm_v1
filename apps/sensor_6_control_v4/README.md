# 机械臂控制与六维力传感器采集界面 V4

V4 从 `sensor_6_control_v3` 独立复制创建，V3 文件和配置不受影响。机械臂
通信继续调用项目根目录 `robot_client/`，六维力/力矩传感器通信继续调用
根目录 `sensor_6/`。

## 启动

从项目根目录运行：

```powershell
C:\Users\www61\anaconda3\envs\common\python.exe apps\sensor_6_control_v4\main.py
```

也可进入本目录后运行：

```powershell
C:\Users\www61\anaconda3\envs\common\python.exe main.py
```

## 文件说明

- `main.py`：程序入口、线程调度、机械臂与传感器调用、试验控制及 XLSX 保存；
- `main_window_4.py`：V4 界面交互、图表、参数记忆与控件尺寸控制；
- `main_window_4.ui`：V4 Qt Designer 界面；
- `sensor_6_control_v4.spec`：PyInstaller 可复现打包配置；
- `sensor_6_control_v4.ini`：首次运行后生成的 V4 独立参数和位置记忆；
- `picture/`：窗口图标和吉林大学校徽。

## V4 界面变更

- 末端增量位移、末端全局位移、增量关节和全局关节各增加一个“重置”
  按钮；重置只清空该组六个输入值，不发送机械臂运动命令；
- 末端位姿和关节角实时显示、位置记忆及六维读数区域采用更紧凑的纵向
  间距；
- 末端和关节速度滑条统一左对齐，关节速度标题统一为“速度 (deg/s)”；
- 四个运动按钮与四个输入重置按钮统一为 100×32 px；重置按钮使用黄色
  高亮，贯入、剪切、铲挖试验的重置按钮也使用相同的高亮语义；
- 六维力/力矩读数首行紧贴标题区域，并在启动时重新计算右侧堆叠页宽度，
  防止较窄右栏裁掉试验按钮；
- P1～P5 槽位靠左排列，并为完整的六轴位置文本保留更宽显示区；完整值也
  可通过鼠标悬停提示查看；
- “明亮主题”和“退出”按钮在吉林大学校徽右侧上下排列。
- 机械臂连接区改为单行：IP、端口、连接状态和一个连接/断开切换按钮；
  传感器连接区也改为单行：串口、刷新、连接状态和一个切换按钮。两个
  按钮均以真实连接结果切换文字及颜色，连接过程中会暂时显示“连接中…”；
  连接与刷新按钮统一为 30 px 高，刷新按钮加宽到 60 px，两套状态灯和
  “未连接/已连接”文字固定靠右排列。

## 剪切试验启动修复

V4 在贯入/剪切试验状态中增加“运动命令已确认”门控。启动试验时先建立
采集基线并发送运动命令，在机械臂工作线程确认命令已经发送后，才允许
到位或力矩阈值逻辑提交安全停止。这样可避免起始预载荷或首帧数据让高
优先级停止命令抢先清空尚未执行的 J6 增量运动。

剪切角位移支持正负值：正值和负值分别控制 J6 的两个方向；运动期间以
Tz 判断扭矩上限并以 20 Hz 采集数据。

## 试验与保存

- 贯入试验保存 `pen_motor_时间_编号.xlsx`；
- 剪切试验保存 `cut_motor_时间_编号.xlsx`；
- 铲挖试验按 B、C、D、E、F、G 的非零 XYZ 增量依次运行，并保存
  `shovel_motor_时间_编号.xlsx`；
- 贯入和剪切数据包含起点置零后的六维数据、世界位姿及 J1～J6；
- 铲挖数据还包含当前阶段、相对 XYZ 位移和累计空间位移；
- 默认保存目录为桌面。

## 配置隔离

V4 参数保存在应用目录的 `sensor_6_control_v4.ini`，与 V2、V3 分开：

- `position_memory`：P1～P5 世界坐标或关节角位置；
- `test_parameters`：贯入、剪切、铲挖的输入参数。

源码运行时 INI 位于本目录；EXE 运行时位于 EXE 同级目录。参数修改后
立即保存，正常退出时再次同步。
