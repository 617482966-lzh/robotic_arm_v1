# 机械臂控制与六维力传感器采集界面 V4

V4 从 `sensor_6_control_v3` 独立复制创建，V3 文件和配置不受影响。机械臂
通信继续调用项目根目录 `robot_client/`，六维力/力矩传感器通信继续调用
根目录 `sensor_6/`。

```powershell

```

也可进入本目录后运行：


## 文件说明

- `main.py`：程序入口、线程调度、机械臂与传感器调用、试验控制及 XLSX 保存；
- `main_window_4.py`：V4 界面交互、图表、参数记忆与控件尺寸控制；
- `main_window_4.ui`：V4 Qt Designer 界面；
- `wrench_plot.py`：六维实时曲线的背景缓存、坐标范围和局部重绘；
- `sensor_6_control_v4.spec`：PyInstaller 可复现打包配置；
- `sensor_6_control_v4.ini`：首次运行后生成的 V4 独立参数和位置记忆；
- `picture/`：窗口图标和吉林大学校徽。

## 手动增量限制与 200 N 力保护（2026-10-29）

末端位姿控制中，增量 X、Y、Z 各自限定为 `-100～100 mm`。输入框、
界面发送函数和主控制器入口均检查该范围。该限制只针对手动“增量位移”，
世界坐标绝对目标、姿态角以及贯入/铲挖试验各自的路径参数保持原有语义。

六维力/力矩读数框新增“200 N 急停保护”切换按钮，每次启动默认开启。
连接传感器后，`abs(Fx) > 200`、`abs(Fy) > 200`、`abs(Fz) > 200`
任意一个成立就触发急停。正负载荷均检查；恰好 200 N 不触发。判断采用
传感器当前读数，不使用试验开始后置零的相对力；Tx/Ty/Tz 不参与此保护。

保护在采集线程中先执行检查并同步提交最高优先级 `stop`，随后才通知
界面更新数字和图表；机械臂使用 `RobotComm.emergency_stop()` 对应的
`stopButton`，待执行的运动队列会被清空。首次连接握手和重新开启保护
时也检查当前力。保护作用于手动运动和全部试验，不依赖试验是否运行。

触发后锁住新的运动命令，结束当前试验并保留已采集数据；持续超限不会
反复堆积急停命令。载荷恢复后点击“使能”解除锁存，载荷仍超限时不能
重新使能。关闭该开关会停止此软件保护并解除其锁存。

采样仍为 20 Hz：收到有效超限样本就提交急停，不等待 GUI 绘图。软件
检查存在采样间隔，且已经进行中的同步 TCP 请求无法中途抢占；实际机械
停止时间还取决于通信和机器人控制器响应。此次验证使用模拟硬件，未做
真实机械臂超载停止试验。

## 六维图表优化与验证

图表使用长度为 5000 的环形缓冲区保存全部六通道显示样本；采样回调只
入队，绘图由可见页面的 100 ms 定时器处理。隐藏页面不扫描历史、不重算
坐标；切回、显示、重置、切换主题和改变窗口尺寸时正确刷新。

`wrench_plot.py` 缓存背景及图例，通常只重画六条曲线；时间轴以 10 s
分段扩展，纵轴按数据范围调整。5000 点内不抽样丢弃峰值。试验仍以 20 Hz
采集/导出，显示刷新频率不会改变 XLSX 数据。

在当前 PC 的 1000×800 画布、6 通道×5000 点、30 帧离屏基准中，旧的
完整重绘中位耗时为 61.48 ms，优化后为 10.72 ms（约 5.7 倍）；该数字
表示稳定坐标范围下的绘图耗时，实际结果与窗口尺寸、机器性能有关。

从项目根目录复现检查：

```powershell
python -B -m unittest discover -s tests -v
python -B tools/benchmark_v4_wrench_plot.py --frames 30
```

24 项自动检查覆盖正负三轴阈值、急停先于 GUI、队列与断开优先级、
初次握手、重新开启、显式使能恢复、增量边界、峰值/历史保留、隐藏/重置
及图例缓存的像素正确性。

## 剪切试验启动修复

V4 在贯入/剪切试验状态中增加“运动命令已确认”门控。启动试验时先建立
采集基线并发送运动命令，在机械臂工作线程确认命令已经发送后，才允许
到位或力矩阈值逻辑提交安全停止。这样可避免起始预载荷或首帧数据让高
优先级停止命令抢先清空尚未执行的 J6 增量运动。

剪切角位移支持正负值：正值和负值分别控制 J6 的两个方向；运动期间以
Tz 判断扭矩上限并以 20 Hz 采集数据。

## 配置隔离

V4 参数保存在应用目录的 `sensor_6_control_v4.ini`，与 V2、V3 分开：

- `position_memory`：P1～P5 世界坐标或关节角位置；
- `test_parameters`：贯入、剪切、铲挖的输入参数。

源码运行时 INI 位于本目录；EXE 运行时位于 EXE 同级目录。参数修改后
立即保存，正常退出时再次同步。
